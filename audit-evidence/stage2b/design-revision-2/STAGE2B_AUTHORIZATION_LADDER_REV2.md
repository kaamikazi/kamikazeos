# Revision 2 Authorization Ladder

**NO AUTHORITY IS GRANTED BY THIS DOCUMENT.** Design, preparation, calibration,
execution and acceptance are separate events. No implied next-stage approval.
Every FAIL or UNVERIFIED stops the affected progression and preserves evidence.

## H0: Pure Host Data, Separate From A1

```text
H0-I owner consideration/decision
  -> H0 host-only implementation, only if authorized
  -> independent H0 input/observer review
  -> separate H0-C owner decision
  -> only if authorized: finite host-control execution
  -> independent result review
```

H0-I retains its previous ready-for-owner-consideration scope: implementation
of the specified56 interpretation rows, bound reference bytes and clearly
synthetic inputs. It does not authorize H0-C, a kernel/VM/device hook, RTC/live
entry calibration, diskfixture, or an A1 guest case. No H0 code/input/runner or
control execution is created in Revision2.

H0 observer review requires actual immutable inputs/expected outcomes, strict
mode/schema/error handling, bound static references and all56 row IDs. Synthetic
positive attestations qualify interpretation only; they do not attest to real
event producers. A later change of observer requires its own version/review;
failed H0 evidence cannot be overwritten or hidden by later passing outputs.

## A1: Fixed A1-UD-1020, All Prerequisites Mandatory

```text
A1-I separate owner preparation decision
  -> isolated default-off A1 implementation/preparation, if authorized
  -> independent actual-build review
  -> independent B-RAM observer/ownership review
  -> CMOS calibration review
  -> writer/device calibration review
  -> separate A1-E authorization decision
  -> only then possible one-instance A1 execution
  -> independent result review before any repeat or later case
```

The calibration reviews above require evidence. Obtaining it through actual
calibration workload, host controls, faults, model changes or builds is **not**
implicitly authorized by the review step or by A1-I. Each such action needs its
own explicit bounded owner decision after the proposed calibration input/model/
observer is reviewed. In particular, positive healthy #UD/panic writer
calibrations are fault executions outside A1 and H0; they remain unauthorized.

|---|---|---|
| A1-I | New isolated source paths/state allocation, unchanged trigger geometry, default-off control, explicit build permission if requested. | Any run, model calibration, production edit or P1/R1 fixture. |

document cannot substitute for a missing artifact or owner's explicit grant.

## Later Independent Decisions

P1-NC, P1-ND and P1-LK remain distinct later owner proposals with their own
topology/seed/state/sensor/calibration gates. Their lower-guard/no-controller
conditions do not weaken A1's healthy storage requirement or writer prohibition.
R1 retains its eligible-parent/first-primary-emitter/preauthorization checkpoint,
actual secondary event/frame and frozen128/100 contract; prior R2 execution is
not required. No P1/R1 build/run is bundled with H0 or A1.

Additional A1 positions/#PF, R2/R3, P2, UART U cases, R-D/R5, P3 writes/flushes,
NMI/tertiary/recursive/busy-TSS experiments and future AI-native features retain
their Revision1 deferrals. Stage2A is preserved history, never rerun as an
implicit prerequisite here. No Ring3/protection activation or END Engine work.

## Universal Stop

Missing ownership, sensor coverage or evidence -> UNVERIFIED and stop. Observed
forbidden store/entry/request/vector/resume/reset -> FAIL and stop. Freeze all
raw files and the first failure; no mask expansion, alternate checkpoint,
automatic retry, observer patch or result rewrite is allowed to rescue it.
Any proposed design/observer change gets a new directory/version/review and
owner decision. Historical missing paths/refs are not restored to make a
preservation inventory appear equal.
