# KamikazeOS Dashboard — arrives in Phase 6

A local web UI that reads state from the host-side AI Recovery Core and
update system: system health, device list with attach status (EXACT /
FALLBACK / ISOLATED / UNKNOWN), AI explanations of incidents, recommended
upgrades from verified sources, recovery history timeline, and rollback
controls. Every action it offers still routes through the policy engine —
the UI gets no special powers.
